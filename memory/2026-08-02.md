## Key Design Decisions

**Owner/Resident Portal as Value-Add:**
- Built to be optional feature (not in basic package)
- Needs admin-level toggle to enable/disable
- Uses same authentication but with resident role checks
- Session-based access control (URL unit IDs don't grant access)
- Simplified views (no internal notes, private vendor credentials, board discussion)

**Naming:** Using "resident" and "owner" interchangeably - both access same portal
