## ProductDyno Setup

1. **Add Tailwind CDN to Custom Code (global):**
   ```html
   <script src="https://cdn.tailwindcss.com"></script>
   ```

2. **For each lesson:**
   - Create lesson in ProductDyno
   - Add HTML/code block
   - Paste content from `-inner.html` file
   - Add video block (YouTube URL)
   - Add quiz from `quizzes.txt`

3. **Set lesson order and locking** in ProductDyno LMS settings
